# 중심 명사 판정 문형 표 (G45–G51, G49 조사)

매퍼 v2 builder 2.4.0, 기본 형상 사전 `base_shapes.v1.json` 0.7.0, 후보 생성기 `ifs-candidates/0.5.0`(2026-11-23). 연구 책임자 결정 G45–G51(`docs/decisions.md`)을 구현하면서, 규칙으로 중심 명사를 정하지 못하거나 틀리게 정하는 문형을 합성 문장으로 찾아 정리했다. 모든 문장은 합성 대사다(AGENTS.md 6). held-out 코퍼스는 열지 않았다. 테스트로 고정한 사례는 `chatbot/tests/test_g45_exclusion.py`.

## 1. 규칙 요약

- **명사구** = 띄어쓰기 없이 붙은 명사 연속(Kiwi NNG·NNP) 앞에, 같은 절의 띄어 쓴 맨 명사 어절(조사 없이 명사만)을 붙인 것. '아이 장난감 상자', '사람 형상', '피 웅덩이'.
- **중심 명사** = 명사구의 마지막 명사. 그것이 `rules.lightHeads`(형상·모습·모양·형태·꼴·형체·생김새·윤곽·실루엣·그림자·끝·끝부분)이고 앞에 명사가 있으면 앞 명사로 옮긴다('사람 형상' → 사람, '칼끝'(Kiwi 칼 + 끝) → 칼). 나머지 명사는 꾸미는 말.
- **한 토큰 합성어**('칼날'·'칼집'·'핏방울')는 Kiwi가 안을 나누지 않으므로 범주별 `compounds` 목록에 있으면 그 낱말 전체를 목록 낱말로 본다(뜻의 중심이 '집'인 '칼집'도 목록이 막는다 — G47 용도). Kiwi가 둘로 자르는 합성어('여자아이'·'꼬마전구'·'해골바가지'·'피범벅')는 위 규칙대로 마지막 명사가 중심.
- **비교(처럼·같은·같이·마냥·듯한)의 원천**은 꾸미는 말이다. 대상은 ① 관형형('같은'·'처럼 생긴')이면 뒤 명사구(사이의 다른 관형형 어절은 건너뜀), ② 서술형('같아요'·'처럼 생겼어요')이면 같은 절의 앞 주어, 없으면 같은 문장 앞 절의 주어(가까운 것부터), 주어가 대명사·형식 명사면 그 절의 서술 명사('그건 귀신인데'), ③ 대상이 형식 명사(`rules.formalNouns`: 것·거·무엇·무언가 …)면 비교 원천이 곧 형상, ④ 비교 표지 뒤 용언이 1층 사전 색 낱말이거나 대상이 색 명사('색'·'빛')면 색 비교(G50 (2)), ⑤ 찾지 못하면 불명.
- **판정:** 중심 명사가 목록 낱말(제외 4범주·동물)이면 그리지 않고 형태 자리로 넘김(`value.formSaid`). 꾸미는 말·비교 원천이면 중심 명사를 그림. 넷째 범주(죽음·자해·외상)는 자리와 상관없이 형태를 막음(색 비교·색 표현 빼고).
- **보수적 기본(판정 못 함):** 비교 대상이 불명이거나 대명사·생략이면, 같은 문장 또는 앞 문장에 형태 자리의 목록 낱말이 있을 때 그리지 않는다(`blockedBy.rule` = `unresolved_reference`). 같은 절의 주어와 서술 명사 중 하나가 목록 낱말이면('끈이 귀신이에요') 다른 쪽도 그리지 않는다(`copula`). 넷째 범주는 문장 범위를 가르지 않고 텍스트 전체의 형태를 막는다.

## 2. 문형별 판정

"판정"은 규칙이 중심 명사를 정할 수 있는지: **가능** / **불확실**(규칙은 정하지만 틀릴 수 있음) / **못 함**(보수적 기본으로 처리). 예문은 제외 범주를 `귀신`(threat)으로, 동물을 `뱀`으로 바꿔 넣어도 결과가 같다(동물은 사유만 `no_asset`).
