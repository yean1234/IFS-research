## 5. 판정 집계

### 5.1 형태 반영(속성 i, 규칙 판정)

판정 규칙(`analyze.py` 첫머리)은 다음과 같습니다.
- form.type 슬롯이 있는 형태(안개·덩어리·껍질·조각): fidelity 상태 그대로 씁니다.
- 둥근·네모·납작·뾰족: `_unmapped`에 같은 모양 값(round·square·flat·pointed)이 있으면 반영입니다. 이 값은 Unity가 모양 모형으로 그립니다.
- 슬롯이 없는 형태(실·선·종이·천·액체·빛·구멍·사람·동물): 그 구절이 form.type 값을 만들었으면 왜곡, `_unmapped`에 근거가 있으면 미반영, 아무 데도 없으면 기본값입니다.
- 형상 없음: form.type이 비어 있으면 "반영(비어 있음)"입니다.

열 이름은 반영 / 반영+form(모양 값과 form.type이 함께 들어감) / 미반영(_unmapped) / 왜곡 / 기본값입니다.

## 7. 가장 눈에 띄는 실패

1. **M12·M04 "거의 투명"이 화면에서 사라짐**: v1에서 opacity 0이 되어 visiblePixels 0입니다. 조건 2(M12)도 같습니다. 근거는 `opacityLexicon.투명>transparent`이고, '거의'가 무시됩니다.
2. **M28 구멍이 공으로 그려짐**: "동그란 구멍"의 '동그랗'이 구 모형(shapePrefab Sphere)이 되어, 빈 것이 채워진 회색 구로 보입니다.
3. **M31 고양이의 자세가 맥락 문장에서 옴**: posture=lying인데, 근거가 떠올린 상황 문장 "소파에 누웠을 때요"(참여자 자신)입니다. 기대는 curled였습니다. 비슷하게 M23 "제가 서 있는 자리" → standing, M35 "몸이 … 처져요" → drooping으로 참여자 자신의 자세가 형상 자세에 들어갔습니다(배경 오염).
4. **M26 촛불이 파란 공이 됨**: "아래는 파랗고 위로 갈수록 주황색" 중 먼저 나온 파랑이 색이 되고(주황은 `_alternatives` later_mention), 형태(불꽃)는 근거가 없습니다. 두 색 섞임 5개는 모두 한 색만 슬롯에 들어갑니다. v1은 둘째 색 원문을 5/5 보존하고, v0는 2/5만 보존합니다.
5. **위치어가 크기·거리로 새어 화면이 깨짐**: M27은 "머리 위 한 뼘쯤 높이에"의 '한 뼘'이 거리 0.2 m(distance 0)가 되어, 노란빛 대신 탁한 반투명 덩어리가 눈앞을 가립니다(visiblePixels 1,329,489, 밝기 "눈이 부실 만큼"은 v1에서 유실). M15는 "등에 붙어" → distance 0이 되어, 등에 있는 상자가 얼굴 앞 큐브로 그려집니다. M08 v1은 위치 답 "가슴 앞을 덮고"가 size 1.0(1.7 m)이 되어 "가슴을 다 덮을 만큼"(0.667, later_mention)을 이깁니다.

그 밖에 M01 "방을 채울 만큼"은 v1 size 0.62('넓게'의 값)입니다. '방'은 크기 기준으로 쓰이지 않습니다.

## 10. 한계와 못 한 것

- 목업 문장과 정답 라벨(`expected`·`gold`)은 같은 AI 에이전트가 썼습니다. 판정도 AI가 했습니다(형태는 규칙, 화면은 눈 판정). 사람 판정, 사람이 쓴 문장, 실제 참여자 문장은 없습니다.
- 화면 판정은 시트 썸네일(장면 축소 + 형상 주변 확대)을 4행씩 잘라 보고 내렸습니다. 원본 PNG 78개를 하나씩 전부 열어 보지는 않았습니다(M01.v1은 원본 확인). VR 헤드셋에서 본 것이 아닙니다.
- 조건 2는 6개 항목을 한 번씩만 돌렸습니다. 같은 seed인데도 첫 실행과 두 번째 실행의 LLM 출력이 조금 달랐습니다(첫 실행은 기록 필드가 모자라 버리고 다시 돌림). 합성 참여자는 질문 내용과 상관없이 미리 쓴 답을 순서대로 냅니다(시나리오 시뮬레이터 방식).
- 조건 2의 v0 spec(`live/specs_v0_from_live_text/`)은 만들기만 하고 캡처하지 않았습니다.
- 범주별 항목 수가 1–4개라 비율은 방향만 봅니다. 거칠·매끈·거의 투명·반짝·거리는 2개씩입니다.
- 크기 프로브를 컨트롤러가 다시 물었을 때(13개 항목)는 코퍼스 약속대로 [넘어가기]를 눌렀습니다. 실제 면담이라면 참여자가 답했을 수 있습니다.
