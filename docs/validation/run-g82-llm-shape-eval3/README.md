## 알려진 한계 (고치지 않음)

차단 규칙을 풀면 오통과 위험이 커서, 메인 지시대로 고치지 않았다.

- **'낡았어요' 과차단**(2차 3건): 선어말 어미 '었'이 있으면 지난 일로 본다(`past_or_former`). 지금 상태를 말하는 문장도 막힌다.
- **'보면' 과차단**(2차 1건, 3차 4건): 연결 어미 '면'이면 가정으로 본다(`hypothetical`). G77 주석에 "막는 쪽으로 넉넉하다"고 적어 둔 규칙이다.
- **'나사'**(2차 1건): Kiwi가 '딱 나사예요'를 나/NP + 사/VV로 나눠 명사가 없다(`no_noun`). 형태소 분석의 한계다.
- **금지 목록 밖 동물**('도롱뇽', 이번 오통과): 목록 방식이라 빠진 낱말은 통과한다.
- **영어 이름 채점**: 한 낱말 제한 때문에 모델이 두 낱말을 붙여 쓴다(fryingpan·remotecontrol). 허용 목록에 없으면 뜻이 맞아도 채움에 세지 않았다.
