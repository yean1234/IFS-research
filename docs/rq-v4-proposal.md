주장할 차별점(강한 순):

1. **보기만 한 VR 조건.** Shigyo와 Bell 외(2025)는 VR을 VR 밖 방식(심상, 오디오)과 비교했습니다. VR의 이점이 "보여서"인지 "다뤄서"인지 가르지 않았고, Bell은 비활성 VR 통제가 필요하다고 한계에 적었습니다 [전문 일부]. 자기 내면 내용을 외부화한 물체에서 이 둘을 가른 연구는 찾지 못했습니다(검색 범위: 웹, Semantic Scholar, OpenAlex. 없다고 단정하지 않습니다).
2. **'나' 기준 공간과 행동 지표.** 놓은 자리가 곧 거리 자료가 됩니다. Shigyo는 행동 측정을 후속 과제로 남겼습니다.
3. **자기 말에서 규칙으로 만든 물체.** 수작업 모델링 없이, 말하지 않은 속성을 구분해 기록합니다. 다만 "규칙 렌더가 심상을 대표한다"는 근거는 따로 재야 합니다(5.3절).

## 3. 왜 '다른 참여자의 경로'였고, 지금은 어떻게 보는가

RQ V3에서 재생 관찰을 둔 이유:

- 보기만 한 조건에서 물체가 가만히 있으면, 배치 조건과의 차이가 "내가 옮겨서"인지 "물체가 멀어지는 것을 봐서"인지 가를 수 없습니다. 멀어지고 작아지는 것은 보기만 해도 부정 정서를 줄입니다(Davis, Gross & Ochsner, 2011, Study 1) [전문].
- 자기 궤적은 직접 해 본 뒤에만 재생할 수 있어 "이미 해 본 사람"이 됩니다. 연구자가 만든 궤적은 실제 사람의 궤적과 속도·최종 거리가 체계적으로 다를 수 있습니다. 다른 참여자의 궤적을 쓰면 두 조건의 궤적 분포가 설계상 같아집니다.
- 두 사람을 짝지으면 옮기는 사람이 늘 먼저가 되므로 미리 모아 둡니다.

다시 본 약점:

- 남의 궤적은 보는 사람의 뜻과 어긋날 수 있습니다(멀리 두고 싶은데 다가옴). 그러면 통제 조건이 중립적인 "관찰"이 아니라 "통제를 잃는 경험"이 되어, 차이가 나도 배치의 이득인지 재생의 손해인지 가를 수 없습니다(추론. yoked 설계의 체계적 편향은 Church, 1964 [2차 자료]).
- 궤적을 미리 모으는 예비 단계도 사람 참여 연구입니다.
- 대비가 가장 작은 설계입니다. Shigyo가 "VR 대 심상"이라는 더 큰 대비에서도 상호작용을 못 잡았다는 점을 보면, 가능한 표본에서 차이가 안 나올 위험이 큽니다.

제안: **주 비교의 통제 조건을 정지 관찰로 바꿉니다.** 교수님이 정리하신 "외부화 + 인터랙션 대 외부화"와 같고, 문헌이 비어 있다고 적은 것도 "비활성 VR 통제" 수준입니다. 대신 주장은 "배치 경험 전체(거리 변화 포함)의 효과"로 한정하고, 놓은 거리를 기록해 RQ2에서 따로 봅니다. 재생 관찰은 표본이 허락할 때 세 번째 조건으로 넣거나 후속 연구로 둡니다. 구현(기록·재생)은 비용이 작아 시스템에는 넣어 둘 수 있습니다. **⚠ 팀 결정**

## 4. RQ와 방법

### 4.1 연구 질문

- **RQ1 (조작).** 참여자의 말로 만든 VR 물체를 '나'를 기준으로 한 공간에 직접 배치하는 것은, 같은 물체를 보기만 하는 것과 비교해, 그 경험과 나를 구별해 알아차리는 정도를 다르게 만드는가?
- **RQ2 (객관 지표).** 물체와 나 사이의 공간 거리(놓은 거리, 멈춤 거리)는 자기보고 심리적 거리와 함께 움직이는가?
- **RQ3 (탐색, 공간 사용).** 참여자는 물체를 어디에 놓는가(거리·방향·높이), 그리고 그 이유를 어떻게 말하는가?
- 보조: 형상이 "내 것 같다"는 평정과 말한 속성 비율이 위 결과와 어떻게 관련되는가.

가설은 RQ1 하나만 방향을 둡니다(직접 배치 > 보기만). RQ2·RQ3는 추정치와 기술 통계 중심의 탐색입니다. 거리가 크다는 것이 "한 발 떨어져 보기"인지 "피하기"인지는 지표만으로 알 수 없으므로(Bell의 경고, Yaremych & Persky 2019의 지적), "더 알고 싶다 / 주의를 거두고 싶다" 문항을 함께 봅니다.

### 4.2 설계

- 참여자 간 2조건, 무선 배정. 사전–사후 측정.
- **직접 배치**: 컨트롤러로 물체를 잡아 옮기고 놓습니다.
- **보기만**: 같은 공간, 같은 시작 위치의 물체를 같은 시간 동안 봅니다. 고개와 몸은 자유입니다.
- 참여자 내 교차 설계는 권하지 않습니다. Bell 외(2025)가 교차 설계를 쓰고도 첫 조건만 분석했고, 한 번 옮겨 본 뒤의 "보기만"은 같은 조건이 아닙니다.

### 4.3 공간과 배치 과제

- 공간: 경계가 있는 원형 바닥. 참여자가 선 자리가 '나'의 자리입니다(PRISM의 '자기' 원판을 몸으로 대신함). 바닥에 옅은 거리 고리. 가구·벽·소품은 두지 않습니다. 가구는 의미를 끌어들입니다(Shigyo의 면담: 높은 선반보다 낮은 의자가 덜 압도적).
- 물체 시작 위치: 정면 고정 거리(예: 1.5 m, 눈높이 아래). 값은 내부 시행으로 정합니다.
- 지시문(초안, `status: draft`, IRB 대상): PRISM의 "지금 당신의 삶에서 … 어디에 두겠습니까"를 본떠, **방향을 암시하지 않는** 문장으로 씁니다. 예: "지금 이것이 있기에 알맞다고 느껴지는 자리에 놓아 주세요." "멀리"·"치우다" 같은 말은 쓰지 않습니다.
- 형식: 공간 구조·시간(예: 90초)·확정 동작("여기에 둔다")은 고정, 놓는 자리와 다시 옮기기는 자유.
- 팔 길이보다 먼 곳에도 놓을 수 있어야 거리가 자료가 됩니다(광선 잡기 + 스틱으로 당기고 밀기).

PRISM 근거: 리뷰 52편·8,254명, 재검사 r=.95–.98 [전문, Sensky & Büchi 2016. 리뷰 저자가 개발자]. 감정·자기의 일부에 쓴 사례와 VR판은 [못 찾음]이므로, 우리 지표는 "PRISM을 본뜬 미검증 지표"로 씁니다.

### 4.4 절차

1. 챗봇 면담으로 심상을 묘사(기존 그대로).
2. 실험자 확인 화면(말한 것 / 기본값 / 반영 못 한 것) → VR에서 물체 제시 30초.
3. 사전 측정: 자기보고 문항, "내 것 같다" 평정.
4. 조건 단계 90초: 직접 배치 또는 보기만.
5. 사후 측정: 자기보고 문항 → 멈춤 거리(두 조건 공통) → 조작 확인 문항.
6. 짧은 인터뷰(어디에 왜 놓았는지 / 보는 동안 무엇을 했는지).

### 4.6 분석과 표본

- RQ1: 사후 점수를 종속변수, 사전 점수를 공변량으로 한 ANCOVA. 효과크기와 신뢰구간을 먼저 보고합니다.
- RQ2: 멈춤 거리의 조건 차이, 거리 지표와 자기보고의 상관(기술적).
- 표본(양측 α=.05, 검정력 80%, 정규 근사 [하위 에이전트 계산, 확인 필요]):

| 설계 | d=0.5 | d=0.8 |
| --- | --- | --- |
| 참여자 간 t검정 | 집단당 64 | 집단당 26 |
| ANCOVA, 사전–사후 r=.5 | 집단당 약 49 | 집단당 약 21 |
| ANCOVA, 사전–사후 r=.7 | 집단당 약 34 | 집단당 약 15 |

- 집단당 15명(총 30)이면 사전–사후 상관이 .7일 때 d≈0.8만 잡습니다. 선행 연구의 결과로 보면 그보다 작을 가능성이 큽니다. 이 규모에서는 "효과크기 추정과 절차 검증을 위한 예비 연구"로 쓰고, 유의성으로 결론 내지 않습니다.

### 4.7 "어떤 공간에 배치하느냐"를 RQ로 넣는 문제

독립변수로는 넣지 않기를 권합니다.

- 빈 공간 대 방, 닫힘 대 열림의 효과크기 근거를 찾지 못했습니다. 가까운 주제인 공간 거리 점화(Williams & Bargh, 2008)는 직접 재현에서 나오지 않았습니다(Pashler 외, 2012) [초록만].
- 2 × 2로 상호작용까지 보려면 표본이 2–4배 필요합니다.
- 대신 RQ3로 "놓은 자리"를 결과로 기록합니다. 공간 비교는 이 자료를 근거로 후속 연구에서 설계합니다.

## 5. 선행 연구의 시각화 방식

### 5.1 지형

| 방식 | 연구 | 만든 방법 | 심상과 맞는지 평가 |
| --- | --- | --- | --- |
| 사용자가 직접 제작 | Mood Worlds, SelVReflect, MoodShaper | VR 3D 붓·오브젝트 | 하지 않음(직접 만들어 물을 필요가 없음) |
| 연구자 수작업 | Shigyo 2024 [전문] | 참여자 그림 → 연구자가 3D 모델링, 참여자 확인 | 참여자 확인만 |
| 3D 글자·미리 만든 물체 | Prudenzi 2019 [2차 자료], Bell 2025 [전문 일부] | 생각 문장을 3D 텍스트로, 또는 애니메이션 물체에 텍스트를 띄움 | 하지 않음 |
| 에셋 선택 | Painimation(JMIR 2018) [2차 자료], AVATAR therapy(Lancet Psychiatry 2018) [초록만] | 미리 만든 애니메이션·얼굴·목소리에서 고름 | Painimation은 선택 결과를 통증 설문과 상관 |
| 규칙·매개변수 | Inner Garden(CHI 2017) [초록만], Pinilla 외 2021 [전문] | 생체신호 → 지형, 정서 사분면 → 색 명도·채도, 둥근/각진 형태, 입자 속도(Unity) | Pinilla: SAM으로 의도한 사분면과 비교(N=21). 부정 환경이 "보기 좋아서" 정서가가 중간으로 나옴 |
| 생성형 2D | MentalImager(CSCW 2025) [전문], Pinzuti 외 2025(arXiv) [전문], Memory Printer(CHI 2026) [전문 일부] | 키워드·감정 분류 → Stable Diffusion, Whisper → SDXL + IP-Adapter 등 | 외부 평가자 5점 평정, 임베딩 유사도, 질적 |
| 생성형 3D·VR | Refugio(Frontiers in VR 2026) [전문] | 음성 → Wit.AI → Gemma 3 → Sana(2D 후보 3장 중 선택) → Zero123++ → InstantMesh → Unity/Quest 3 | **하지 않음.** 저자가 불일치를 한계로 인정 |

### 5.2 기술 심층에서 가져올 것

- **Refugio**: 공개된 파이프라인 중 가장 자세합니다. 이미지 생성 평균 56.7초 + 3D 변환 60.3초, 서버 TITAN RTX 24 GB 3장, N=30, SUS 86.3. 음성 인식이 클라우드(발화 90일 보관), LLM의 색 편향(빨간 물체 거부) 보고. 코드 미공개.
- **MentalImager**: 키워드 가중치를 사용자가 0.1 단위로 조정. "시스템이 정한 것을 사용자가 사후에 고친다"는 구조의 예.
- **Pinilla 외**: 규칙 기반 방식의 직접 선례. 문헌(Valdez & Mehrabian, Bar & Neta, Lockyer 등)에서 규칙을 가져오고 SAM으로 검증하는 절차를 그대로 본뜰 수 있습니다.
- 규칙의 근거 문헌: 색–감정 30개국 조사(Jonauskaite 외, 2020, r=.88), 곡선 선호(Bar & Neta, 2006), 정서적 색(Bartram 외, CHI 2017), 움직임 질감(Lockyer 외, 2011) [모두 초록만].

### 5.3 공개 3D 생성 모델과 우리 원칙

| 모델 | 라이선스 | 입력 | 판단 |
| --- | --- | --- | --- |
| Shap-E | MIT | 영어 텍스트·이미지 | 품질 낮음, 말하지 않은 세부를 채움 |
| TRELLIS / TRELLIS.2 | MIT | 주로 이미지(텍스트 모델은 덜 세밀하다고 README에 명시) | VRAM 16 GB 이상, 텍스트 → 이미지 단계가 따로 필요 |
| Hunyuan3D-2.1 | Tencent 커뮤니티 라이선스 | 이미지 | 라이선스 적용 지역에서 한국 제외 [확인 필요] |
| TripoSR, SF3D, InstantMesh | MIT / Stability 커뮤니티 / Apache-2.0(가중치 미확인) | 이미지 | 텍스트 입력 없음 |

- 한국어를 직접 받는 모델은 확인하지 못했습니다. 모든 모델이 말하지 않은 형상·재질을 생성 과정에서 채웁니다. 원칙 1(장면 속성은 사전·규칙만), 원칙 2(말하지 않은 것을 추론하지 않음)와 부딪힙니다.
- 결론: 이번 연구는 규칙 기반을 유지합니다. 생성형은 쓰더라도 "미리 만들어 검수한 에셋 라이브러리"(에셋 선택형) 용도가 한계이고, 그때도 원칙 1·2와의 관계를 먼저 정해야 합니다.
- **말하지 않은 속성**: 선행 연구에서 기본값과 미지정을 구분해 표시한 사례를 찾지 못했습니다. 우리는 (i) 기본값으로 그려진 속성을 `_provenance`로 기록하고, (ii) 실험자 확인 화면에서 구분해 보여 주며, (iii) "내 것 같다" 평정과 말한 속성 비율을 공변량으로 씁니다. 참여자가 VR에서 속성을 직접 고치게 하는 방법(Shigyo의 메뉴)은 그 자체가 인터랙션이라 보기만 조건을 오염시키므로 이번에는 넣지 않습니다. 후보1 프로토타입(속성 하나를 바꿨을 때 "내 것 같다"가 얼마나 떨어지는가)은 이 문제를 직접 재는 보조 연구로 남길 수 있습니다. **⚠ 팀 결정**

## 6. 먼저 정해야 할 것

1. **심상의 종류와 심의.** 종속변수가 "경험과 나를 구별하기"이므로 중립 물체 심상(후보1)으로는 성립하지 않습니다. 자기와 관련된 심상을 쓰면 사람 참여 연구 심의 확인이 먼저입니다(예비 시행 포함). Shigyo의 기억 쓰기 유도(AEMT)는 원칙 3(기억 질문 금지)과 맞지 않아 쓰지 않습니다.
2. 통제 조건: 정지 관찰(제안) / 재생 관찰(V3) / 둘 다.
3. 주 측정 척도와 한국어판 확인.
4. 현실적인 표본 규모와 그에 맞는 주장 수위.
5. Quest 3 실기 실행 가능 여부. 잡기·광선 조작에는 XR 패키지 추가가 필요합니다(X27에서 미룸).
