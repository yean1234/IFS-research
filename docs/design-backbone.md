# 설계 뼈대

이 연구 파이프라인의 개발은 이 문서를 뼈대로 한다(연구 책임자 결정, 2026-11-27).
원본은 노션 「심사자 눈으로 본 설계 점검과 보완 — RQ3 질문 만들기 (11/25)」(페이지 ID `423ed99f9ad581229d41eb5a903c8966`)이고, 저장소의 결정 기록은 `docs/decisions.md` G59다. 이 문서는 그 페이지를 옮긴 요약이다. 노션 페이지와 어긋나면 노션 페이지가 우선이고, 이 문서를 고친다.

## 쓰는 법
- 새 기능·문구·설정을 만들거나 고치기 전에 아래 뼈대의 어느 칸에 해당하는지 먼저 확인한다.
- 뼈대와 어긋나는 변경은 하지 않는다. 꼭 필요하면 어긋나는 점과 이유를 `docs/decisions.md`에 적고 연구 책임자에게 알린다.
- 뼈대가 정하지 않은 것은 `AGENTS.md`의 작업 원칙과 기존 결정을 따른다.
- 하위 에이전트와 Codex에 설계·검토를 맡길 때 이 문서를 읽을 것에 넣는다.

## 1. 연구가 묻는 것
걱정이 곧 '나'처럼 느껴질 때, 그것을 눈앞의 물체로 꺼내 놓고 보면 한 발 떨어져 볼 수 있다. 이 '한 발 떨어진 느낌'이 **거리감**이다(그것과 나를 따로 떼어 알아차리는 느낌. 멀리 도망가는 것과 다르다).
묻는 것은 하나다: 꺼내 놓은 것을 **보기만 할 때**와 **내 손으로 자리를 정해 놓을 때** 거리감이 다르게 생기는가.

| 질문 | 내용 | 무엇으로 답하나 |
| --- | --- | --- |
| RQ1 | 직접 놓으면 보기만 할 때보다 거리감이 더 생기는가 | 문항 점수의 사전→사후 변화를 두 집단끼리 비교 |
| RQ2 | 공간의 거리가 마음의 거리감과 함께 움직이는가 | 멈춤 거리·놓은 거리와 문항 점수의 관계 |
| RQ3 | 물체를 어디에 놓고, 그 자리를 어떻게 말하는가 | 놓은 자리 기록과 RQ3 질문(4절) |

## 2. 진행 순서
면담(떠올리기) → 물체 고르고 고치기 → 사전 문항(컴퓨터) → 헤드셋 → 직접 배치 또는 보기만 → 사후 문항 → 자리 문항 → 멈춤 거리 → 헤드셋 벗고 짧은 면담.

- 말이 물체가 되는 길: LLM은 면담 질문을 만든다. 물체는 사전과 규칙이 만든다. 같은 말이면 같은 물체가 나온다(형태 메시 후보의 예외는 `AGENTS.md` 원칙 1·2). **2026-11-28 변경(G77, 연구 책임자 결정): 사전·규칙이 비운 슬롯은 LLM이 참여자 원문 인용을 단 값을 조절 화면의 처음 값으로 제안할 수 있다. 확정 스펙은 그대로이고 출처를 따로 적는다. 이 값에는 "같은 말이면 같은 물체"가 캐시·기록으로만 성립한다. 원본 노션 페이지와 달라진 곳이다.**
- 두 집단은 배치 구간(90초)만 다르다. 점수 차이를 "직접 놓은 경험" 때문이라고 말할 수 있게 그 밖의 것은 같게 둔다.
- 놓은 자리는 거리·방향·높이로 적는다. 보기만 집단은 놓은 거리가 없으므로 두 집단 모두 멈춤 거리 과제로 거리 값을 얻는다.

## 3. 본 실험 권고 설정
| 항목 | 값 | 까닭 |
| --- | --- | --- |
| 공간 | B 빈 바닥 + 놓기 도움 | 분위기를 끌어오지 않고 어두운·밝은 물체가 모두 보인다 |
| 연습 | 두 집단 모두 | 조건 전 경험을 같게 |
| 문항 순서 | 자리 문항 → 멈춤 거리 | 멈춤 거리가 답을 바꾸기 전에 묻는다 |
| 문항 중 물체 | 숨김 | 눈에 보이는 거리가 답에 섞이지 않게 |
| 초안 경고 줄 | 참여자 화면에서 숨김 | 몰입을 깬다. 연구자 화면·기록에는 남긴다 |
| 조건 수 | 2개(직접 배치 / 보기만) | 20명 규모에서 세 집단은 인원이 모자란다 |

코드 기본값은 바꾸지 않는다. 위는 실험을 돌릴 때 켜는 값이다.

## 4. RQ3 질문의 구조 (모두 초안)
세 층이다: 점수 → 말 → 다시 점수.
- A(헤드셋 안, 1–7점, 두 집단): 자리가 알맞았는가, 옮기고 싶었는가.
- B(벗은 뒤, 말로): 그 자리가 어떤 자리였는지(B1), 그때 '여기다'를 어떻게 알았는지(B2, 직접 배치) / 무엇을 알아차렸는지(B2′, 보기만), 참여자 낱말로 되묻기 최대 2번(B3), 그때 안 것인지 지금 떠오른 것인지(B4), 한 줄로 적기(B5).
- C(맨 끝, 1–7점, 직접 배치): 자리를 정할 때 영향을 준 것들.
- D(두 집단): 문항의 대상을 무엇으로 읽었는지(D1), 연구가 무엇을 알아보려 한다고 생각했는지(D2).

만드는 규칙:
- "왜"를 묻지 않는다. "그때 어떻게 알았나요"로 묻고, 답은 설명으로만 쓰고 원인의 증거로 읽지 않는다.
- 실험자는 참여자 낱말만 되돌린다. "멀리", "가까이", "피하다", "편하다"를 먼저 꺼내지 않는다.
- 보기 낱말이 든 평정(C)은 맨 끝에 둔다.
- 보기만 집단도 자리 문항에 답한다.
- 녹음하지 않고 받아 적는다.

문구 원문은 `shared/protocol/post_interview.v0.json`, 실험자 대본과 정리 틀은 `docs/post-interview-guide.md`.

## 5. 심사자 지적과 보완 — 새 변경이 깨면 안 되는 것
| 지적 | 지키는 것 |
| --- | --- |
| 두 집단이 '놓기' 말고도 다르다 | 연습은 두 집단 모두. 논문에는 "직접 배치 묶음"의 효과라고만 쓴다 |
| 안내문이 답을 미리 정한다 | 물체가 떠올린 것을 나타낸다고 단정하지 않는다 |
| 문항에 답할 때 물체 위치가 다르다 | 문항 동안 물체를 숨긴다 |
| 자리 문항이 멈춤 거리 뒤에 있다 | 자리 문항을 멈춤 거리 앞에 둔다 |
| 거리감을 직접 묻는 문항이 없다 | 거리감 문항과 구별 문항을 둔다 |
| 걱정이 얼마나 센지 모른다 | 강도 문항 하나를 둔다 |
| 문항의 대상이 흐리다 | 끝에 무엇으로 읽었는지 묻는다(D1) |
| 참여자가 목적을 눈치챌 수 있다 | 끝에 묻는다(D2) |
| 주 지표가 정해지지 않았다 | 얽힘 7문항 총점이 주 지표(교수님 확정 전) |

## 6. 자료를 보기 전에 정해 둔 분석 규칙
- 사람을 빼지 않고, 빼고 다시 봐도 같은지를 함께 보고한다: 대표성 문항 2점 이하이거나 "맞는 게 없어요"를 고른 사람 / 연구 목적을 맞힌 사람 / 문항의 대상을 의도와 다르게 읽은 사람 / "지금 떠오른" 설명(RQ3).
- 놓은 거리와 멈춤 거리의 닮음은 직접 배치 집단 안에서 따로 보고한다.
- 결과의 범위는 "한 번의 만남, 병이 없는 성인, 약한 걱정, 그 순간의 상태"로 좁혀 쓴다.

## 7. 남은 약점 (숨기지 않는다)
IRB 심의 없이 진행(지도교수 결정 G68, 보호 절차는 `docs/participant-protection.md`), 자리 정하기와 손 조작을 가르지 못함, 적은 인원(예비 연구), 물체에 대한 멈춤 거리는 처음 쓰는 지표, 사전에 없는 낱말, 번안 문항의 원문 대조와 사용 허가, 헤드셋 실기 확인.

## 8. 11/25 뒤에 바뀐 것 (뼈대 위의 변경)
- 면담 첫 질문이 '우선순위가 가장 높은 일'로 바뀌었다(G60).
- 문항의 대상 호칭: '이것'을 '그 느낌'(그 일을 떠올렸을 때 든 느낌)으로 갈랐다. 물체·자리 문항은 '이것' 그대로. D1과 분석 규칙도 그에 맞췄다(G65·G66).
- 형태 메시 후보를 로컬 생성 모델로 더하는 경로(G62), 헤드셋 UI 가독성(G63), 감정어 다리 질문(G64).
