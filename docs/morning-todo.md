## 결정이 필요한 것
- [ ] LLM 구조화 추출을 세 번째 비교 조건으로 넣을지. 넣으려면 AGENTS.md 원칙 1을 고쳐야 합니다(decisions.md D03).
- [ ] 신체 부위어 → 높이: v0는 '가슴'에서 `layout.verticalOffset = 0.72`를 만들지만, dev 코퍼스는 공간 높이어가 있을 때만 높이를 정답으로 둡니다. dev 18개 항목이 여기서 갈립니다. 어느 쪽을 따를지 정한 뒤 코퍼스나 scene_params를 고칩니다.
- [ ] 프로브 건너뛰기 규칙(controller.py, `coveredByCategories`): '작은', '떠 있어요', '갈색' 같은 낱말 하나만 나와도 그 차원 프로브 전체를 건너뜁니다. dev 재생에서 슬롯 답 12개가 이 때문에 빠졌습니다. 바꾸려면 shared/protocol 버전을 올려야 합니다.
- [ ] 짧은 '모르겠어요' 답은 no_more로 분류되어 확정 텍스트에서 빠집니다. 그래서 SceneSpec에서 '말하지 않음'과 '모른다고 말함'이 구별되지 않습니다. 'unknown' 표시를 넣을지 검토합니다(원칙 2).
- [ ] 코퍼스 정답 구간 검토: dev.json·heldout.json의 크기 구간, 색상 구간, body_layer 후보. 특히 heldout은 최종 평가 전에 사람이 한 번 보고 고정해야 합니다.
- [ ] Unity 형태 에셋 4종의 size 0.5 물리 크기(m)를 정하고, 크기 정답 구간을 좁힐지
- [ ] mist 프리셋이 매우 옅음(opacity 0.6일 때 가운데 덮임 0.26, 장면 ΔE00 12.9). 밀도 프리셋을 올릴지
- [ ] 유채색 렌더 편차: 말한 유채색의 ΔE00이 합성 spec에서 6.3–8.1(무채색 EX01은 1.2). 논문 해석에 적을지, 셰이더를 보정할지
- [ ] `unity/ProjectSettings/SceneTemplateSettings.json`(Unity 자동 생성)을 계속 커밋할지
- [ ] **drift 판정용 새 독립 라벨 세트.** AC-2는 라벨 18개에서 정확도 1.000이지만 "잠정 통과"입니다. 라벨에 나온 사전 낱말 4개(날개·보풀·돌멩이·뭉치)를 빼면 0.833으로 기준(0.90)에 못 미치고, 설계자가 라벨을 읽은 뒤 규칙을 썼습니다. 규칙·사전을 보지 않은 사람이 새 라벨을 쓰고 다시 재야 합니다. 검토자 합성 대화 41개(`chatbot/tests/fixtures/drift/review_t2_regression.json`)는 규칙을 고친 뒤 맞춘 것이라 독립 평가가 아닙니다(`docs/drift-design.md` 8.4·9.3절).
- [ ] 자기보고·회상 확인 문구(protocol v1.1, draft): '처음 적어 주신 그것'은 면담 안의 첫 답을 회상하게 하고, 회상 확인 선택지 '조금 달라졌어요 / 많이 달라졌어요'는 심상이 바뀌었다는 암시가 될 수 있습니다(요구 특성). 선택지를 중립(같아요 / 달라요 / 넘어가기)으로 바꿀지 팀·IRB 검토에서 정합니다. 회상 확인 문구는 지금 검증기 V1–V9를 거치지 않습니다(`docs/chatbot-design.md` 5-2절).
- [ ] drift 보류 항목: 무채색 변화 기준(검정→회색은 유지, 흰색→회색은 모순으로 나옴), 대상이 여럿일 때 절 단위 연결(지금은 `multipleObjects` 표시만), 숫자 뒤가 아닌 '개'(동물) 처리, 크기 낱말과 비교·측정 크기가 섞일 때의 큰 차이('작은' → '수박만'을 놓침).
- [ ] 매핑이 읽는 신체 위치: '목 앞쪽'을 around_front(몸 밖 앞)로, '가슴 가운데'와 '명치'를 포함 관계 없는 다른 부위로 읽습니다. drift 오탐의 원인이 됩니다. 사전(scene_params)을 고칠지 정합니다.
- [ ] 매핑 v1 한계: 한 문장에 대상이 여럿이면 먼저 말한 대상의 속성이 형상 값이 됩니다('인형 옆에 빨간 컵이 있고 저는 작은 파란 구슬이에요' → 빨강). 색 낱말 오타('빨깐')는 값 없이 원문만 남습니다. 퍼지(자모) 일치는 이제 값에 쓰지 않고 확인 필요 후보로만 남기는데, 확인 질문 루프를 켜면 흔한 낱말('설명', '심정')도 후보로 물을 수 있어 퍼지 대상을 좁힐지 정해야 합니다.
- [ ] Unity가 `_uncertain`('모른다고 말함')과 단순 미지정을 똑같이 DefaultsUsed로 기록합니다. 조정량 분석에서 둘을 가르려면 SceneParams에 목록을 따로 둬야 합니다.
