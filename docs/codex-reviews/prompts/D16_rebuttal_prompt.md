너는 이 연구 저장소의 외부 감시자다. 파일을 수정하지 말고 읽기만 해라. 한국어로 답하라.

## 두 안이 같았던 것 (그대로 채택)
- 입력은 확정 텍스트만. 면담자 질문·매퍼 슬롯값은 넣지 않는다.
- LLM은 영어 문장을 통째로 쓰지 않는다. 대상 명사구와 모양 꾸밈 요소를 구조화해 내고 요소마다 원문 근거 구간을 단다. 문장은 규칙이 조립한다. 색·재질·크기·위치·배경·화풍·감정은 넣지 않는다.
- 형태를 말하지 않은 경우 감정·색·감각을 사물로 옮기지 않는다. 규칙이 고정한 중립 형태를 `system_default` 출처로 따로 제시하고, 말한 형태로 분석하지 않는다.
- 영어는 참여자에게 보이지 않는다. 원문 근거 낱말을 보이고 거절할 수 있다. 위기·확인 판정 세션은 캐시 포함 부르지 않는다. 재작성 결과 전문·판·digest·seed·원시 출력·기각 사유·노출·선택·거절을 기록한다. 기본 꺼짐 플래그, 첫 단계는 합성 대사 오프라인 점검.
- 사후 면담에 어긋남·영향 문항을 더하고, 노출 세션을 뺀 민감도 분석을 자료를 보기 전에 정한다.

## 갈린 것과 메인 판정
1. **순서: 규칙 → 자유 재작성(G85).** 규칙이 형태를 잡으면 다시 쓰지 않는다(Claude 안). 네 안(재작성군에서는 규칙이 잡아도 LLM 호출)은 버림. 이유: 규칙 경로는 같은 말에 늘 같은 결과이고, 책임자의 목적은 "생성이 안 되는 경우를 없애는 것"이지 LLM 처치 자체가 아니다. 대신 세션마다 실제로 탄 경로를 기록해 층으로 나눈다. **G82(낱말 하나)는 G85가 켜지면 끈다**(G85의 "근거 있는 대상 명사"가 같은 일을 한다. 두 안 모두 다루지 않은 메인의 단순화).
2. **근거 없는 꾸밈: 닫힌 모양 형용사 목록 안에서 최대 2개까지 허용하고 `added`로 기록·화면 표시(Claude 안).** 네 안(모든 요소에 근거 필수)은 버림. 이유: 모든 요소에 근거를 요구하면 G82에서 낱말 수만 늘린 것이라 원칙 2를 바꾼 것이 아니게 된다. 책임자의 결정은 바꾸는 것이다. 대상 명사 자체는 근거가 있어야 한다.
3. **호출 전 안내·건너뛰기 화면은 넣지 않는다.** 대신 참여자 안내문(동의서)에 "말한 글을 로컬 AI가 읽고 모양을 만들며 말하지 않은 모양이 더해질 수 있다"는 문장을 draft로 더하고, 그림 화면에 근거 낱말·덧붙임 여부·중립 여부를 보인다(Claude 안). 네 안(호출 전 별도 선택)은 버림. 이유: 같은 로컬 모델이 이미 면담에서 참여자 말을 읽고, 단계가 하나 늘며, 안내문에서 미리 알리는 쪽이 맞다.
4. **영어 차단에 WordNet 상위어 검사를 더한다(Claude 안).** 목록 밖 동물(newt)이 낱말 목록을 지난 문제 때문. 로컬 파일로만 쓰고, 넣지 못하면 목록 + 관문으로 간다.
5. **메시 관문 오탐(주전자 0.79, rock 0.78)은 문턱을 낮추지 않는다.** 대신 메시가 막히면 끝내지 않고 남은 그림으로 돌아가 다른 그림을 고르게 한다(두 안 모두 다루지 않은 메인의 추가).
6. **사후 면담 문항 2개(Claude 안 PI9·PI10)를 draft로 넣는다.** 네 안의 문항 3개는 "그림을 보고 달라졌나요"를 직접 물어 유도 위험이 있어 버림.

## 답할 것

- 판정 2에서 근거 없는 꾸밈 2개를 허용할 때 생기는 가장 나쁜 사례와, 닫힌 목록에 넣으면 안 되는 형용사 부류.
