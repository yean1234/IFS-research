너는 이 연구 저장소의 외부 감시자다. 파일을 수정하지 말고 읽기만 해라. 한국어로 답하라.

## 맥락
G82(원칙 1 변경: [맞는 게 없어요] 뒤 LLM이 형태 생성 프롬프트의 형태 낱말을 정함)에 대해 두 독립 설계안을 받았다: 네 안 `docs/codex-reviews/D15.md`, Claude 안 `docs/codex-reviews/D15_claude.md`. 과제는 `docs/codex-reviews/prompts/D15_prompt.md`. 메인이 아래처럼 판정했다. 이 판정을 반박하라.

## 두 안이 같았던 것 (그대로 채택)
- LLM은 프롬프트 문장을 쓰지 않고 {참여자 원문 인용, charSpan, 짧은 영어 형태 이름}만 낸다. 틀·꾸밈말은 규칙이 붙인다.
- 형태를 말하지 않았으면 생성하지 않는다. 규칙 사전이 형태를 잡으면 규칙이 먼저다.
- 면담자 질문은 LLM에 넣지 않는다. 위기·확인 판정 세션은 캐시 포함 부르지 않는다.
- 출력은 G77 검증기의 형태 갈래(인용 일치, 부정·과거·타인·가정·비유, 사람·동물·안개·불꽃)와 영어 금지 목록, 그림·메시 관문을 모두 지난다.
- 근거 인용을 참여자에게 보이고, 아니라고 할 수 있게 한다. 기본 꺼짐 플래그. 첫 단계는 실험 경로에 잇지 않은 합성 대사 오프라인 평가.

## 갈린 것과 메인 판정
1. **입력: 확정 텍스트만(Claude 안) 채택.** 참여자 발화 전체(네 안)는 버림. 이유: 확정 텍스트가 참여자가 확인한 판이고, G77 인용 검증기·매퍼 구간 제외가 이미 확정 텍스트 좌표로 돌아간다. 발화 전체는 참여자가 확정 때 고치거나 뺀 말을 되살린다.
2. **영어 이름: 금지 목록 + 관문만(네 안) 채택.** 새 허용 목록(Claude 안)은 버림. 이유: 허용 목록은 "사전에 없으면 생성 안 됨"을 영어 쪽에서 다시 만든다. 출처·라이선스도 새 부담이다. 대신 영어 이름은 소문자 명사 1–2낱말, 글자·길이 제한, 꾸밈말(색·크기·재질·감정) 낱말 금지 목록을 건다.
3. **부르는 때: [맞는 게 없어요]를 누른 뒤(Claude 안).** 확정 직후 미리 부르지 않는다.
4. **G77-d(G77의 형태 낱말 칸)는 G82가 켜지면 끈다(Claude 안).** 같은 일을 두 경로가 하면 기록이 갈린다.
5. **참여자가 형태 낱말을 직접 고쳐 쓰는 입력 칸(네 안 7번)은 넣지 않는다.** 근거 인용 줄과 [그 말이 아니에요](→ 기존 경로로 되돌아감)만 둔다. 이유: 자유 입력 칸은 원칙 3(예시·선택지·새 질문)과 부딪히고 새 입력에 관문을 다시 걸어야 한다.
6. **실험 적용:** 오프라인 평가가 통과 기준을 넘기 전에는 `experiment.toml`에서 켜지 않는다. 켜는 날부터의 세션은 `shapePromptPath`(rule | llm | none)를 기록해 층으로 나눠 보고한다.

## 답할 것
- 판정 1–6 각각에 대해 동의/반박과 근거. 반박이면 구체적인 실패 입력이나 `파일:줄`.
- 판정 2에서 허용 목록 없이 남는 위험 가운데 금지 목록·관문으로 못 막는 것(재현 값).
- 오프라인 평가의 통과 기준으로 무엇을 몇 건, 어느 수치로 잡아야 하는가(사전 밖 형태 채움률, 부정·과거 오통과, 금지 범주 오통과).
- 두 안 모두 놓친 것.
