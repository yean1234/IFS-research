# D12 독립 설계안: [맞는 게 없어요] 뒤, 참여자가 다시 말한 형태 설명으로 메시를 생성하기

당신은 이 연구 저장소의 설계 검토자다. 다른 설계자도 같은 질문에 따로 답하고 있다. 서로의 답은 보지 않는다. 코드는 고치지 말고 설계안만 낸다.

## 배경
- 연구 책임자 판단(2026-11-28): 지금 형태 메시 생성(G62)은 규칙이 고른 형태 낱말을 고정 한→영 사전(`shared/lexicon/shape_prompt_en.v0.json`)으로 옮겨 SDXL→TripoSG에 넣는다. 사전 범위 밖 낱말은 생성되지 않아 한계가 크다.
- 연구 책임자가 고른 방향(가) "중간안": 후보 화면에서 참여자가 [맞는 게 없어요]를 누르면, 참여자에게 **물체를 만드는 데 쓰인다는 것을 알린 뒤** 형태를 다시 말하게 하고, 그 말로 생성한다. 사전에 없는 낱말도 생성에 쓰일 수 있게 한다. 시스템이 추론한 것이 아니라 참여자가 생성용으로 직접 쓴 말이라는 점이 원칙 2와의 충돌을 줄이는 근거다.
- 지금 [맞는 게 없어요]는 재생성 없이 기준 후보 0번으로 조절 단계에 간다(`chatbot/scenarios/selection/S4_none_fit.json`, `chatbot/ifs_chatbot/web/stage.js` drawSelecting).
- 본 실험 마감 2026-12-02. 본 실험 설정에서 생성 메시는 꺼져 있다(G67-b). 이 기능은 설정으로 켜고 기본은 끈다. 본 실험 적용 여부도 판단하라.
- 실행 환경: Windows PC, RTX 5080 16 GB, Python 3.11, 면담 모델 Ollama gemma4:e4b(digest 기록). 생성 후보 1개 약 27–30초, 최대 VRAM 12.5 GiB. IRB 심의 없이 모집(G68) → 참여자 보호를 약하게 하지 않는다.
- 연구 책임자 시험 세션의 안개 사례: 「검은 안개가 있는 느낌」, 「구름 같은데 구름 보다는 덜 뺵뺵하고 보이지 않는 안개같은?」, 「먹구름」(`chatbot/scenarios/g70_researcher_fog.json`), 「넓게 펼쳐진 안개가 떠오른다」가 뭉친 구름으로 그려짐(G72). 안개·불꽃은 지금 생성 금지(G62-e, `tools/gen3d/prompts.py` nonMeshable).

## 답할 것 (한국어, 150줄 이내, 표 허용)
1. **흐름**: 어느 화면에서 무엇을 묻는가(고정 문구 초안, draft 표기). 몇 번까지 다시 말할 수 있나, 후보 몇 개, 기다리는 동안 무엇을 보이나, 끝내 안 맞으면 어디로 가나. 두 집단이 같게 유지되는가.
2. **입력 거르기**: 다시 말한 글에서 생성 프롬프트로 가는 것과 가지 않는 것. 위기 판정(원칙 4), 감정·감각어, 사람·얼굴·동물, 메시로 안 되는 범주(안개·불꽃), 색·재질, 크기·위치를 각각 어떻게 다루나. 걸러진 것은 참여자에게 어떻게 알리나(알리지 않나).
3. **한국어→모델 입력**: (a) 기존 사전 + 사전 밖 낱말 처리 규칙 (b) 로컬 번역 모델(예: NLLB, 결정적 디코딩, digest 기록) (c) 한국어를 직접 받는 이미지 모델(Qwen-Image 양자화 등) (d) 그 밖. 하나를 고르고 원칙 1의 예외 문구를 어떻게 고쳐야 하는지 정확한 문장으로 제안하라. 결정성(같은 글 → 같은 메시)을 어떻게 지키나.
4. **스펙과의 관계**: 다시 말한 글이 IFSSceneSpec 슬롯(형태 외)을 바꾸는가. 원칙 2 "말한 것이 추론한 것을 덮어쓴다"와 어떻게 맞추나.
5. **기록**: selection 기록(새 판 필요한가), 출처 이름, 원문 저장 위치(참여자 자유 기술은 git에 올리지 않음), 분석에서 이 세션을 어떻게 구분하나(G59-11 민감도 분석과의 관계).
6. **안개 사례**: 위 네 문장을 당신의 설계로 넣으면 무엇이 나오는가, 원하는 모양(넓게 퍼진 옅은 안개)에 가까워지나. 아니라면 그 사례는 어떤 경로로 풀어야 하나.
7. **위험과 시험**: 가장 큰 위험 3개, 꼭 필요한 자동 시험, 이 PC에서 사람이 실측할 것.
8. **본 실험(12-02) 적용 여부**와 이유.
