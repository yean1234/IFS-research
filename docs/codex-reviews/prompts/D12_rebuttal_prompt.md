## 메인 판정 (G73 초안)
1. **바탕은 Claude 안.** 다시 적기 최대 2회, 회당 생성 후보 최대 2개(seed 고정 순서), 대기 중 고정 문구·경과 막대만, 끝내 안 맞으면 지금처럼 기준 후보 0번 → 조절. 원문은 git 밖 `logs/selection/<sessionId>/resay.json`, selection 기록에는 sha256·글자 위치만. selection.v0.4, 출처 `generated_resaid_chosen`. 본 실험(12-02)에는 넣지 않는다(두 안 일치). 설정 기본 끔.
2. **한국어→프롬프트는 Claude 안 (d)**: 손 사전 우선 → 공개 한·영 대역 사전(판·sha256 고정) → WordNet 상위어 범주 거르개(사람·동물·비메시 범주면 차단, physical_entity 뜻이 없으면 버림), 뜻 2개면 뜻마다 후보, 3개 이상이면 버림. 모델 없음 → 원칙 1의 "LLM·번역 모델로 프롬프트를 만들지 않는다"는 그대로 둔다.
   - Codex 안 (a)를 버린 이유: 사전 밖 낱말을 승인 목록에 들어온 뒤에만 쓰면 연구 책임자가 지적한 한계(사전 범위)가 그대로 남는다. 승인 목록을 사람이 미리 채우는 것은 지금 사전 확장과 같다.
   - Codex 안의 "다시 말하기 1회·후보 1개"를 버린 이유: 뜻이 갈리는 낱말에 뜻마다 후보를 내야 시스템이 뜻을 고르지 않는다(원칙 2). 2회는 대기 상한(약 2분)과 소유감 근거(재생성·조절이 필요, Wang 2026) 사이의 타협.
3. **갈래(라우터) 추가 — 두 안 모두에 없던 것(연구 책임자 제안, 2026-11-28).** 다시 적은 글을 같은 매퍼(규칙, 결정적)로 읽어 형태 갈래를 사전이 정한다:
   - ① 단단한 사물 → 생성기(TripoSG, 나중에 Cube 3D를 다른 계열 후보로)
   - ② 안개·구름·연기(form.type mist) → 생성하지 않고 레이마칭 안개 렌더의 값으로
   - ③ 빛·발광 → `material.emission`
   - ④ 불꽃 → 파티클
   - ②–④에서는 다시 적은 글에서 매퍼가 채운 값(밀도어 「덜 빽빽한·옅은」 새 사전, G72 비율 「넓게 펼쳐진」, 투명도, 발광)을 **조절 단계의 처음 값(덮어쓰기)으로 넣고, 출처를 `resaid`로 적는다.** 확정 스펙(면담 글에서 나온 것)은 바꾸지 않는다. 장면 = 확정 스펙 + 덮어쓰기(지금 조절 단계와 같은 구조).
   - 이것은 두 안의 "다시 적은 글은 스펙 슬롯을 하나도 바꾸지 않고 매퍼도 다시 돌리지 않는다"를 뒤집는다. 근거: 참여자가 직접 말한 값이므로 원칙 2의 "말한 것이 추론한 것을 덮어쓴다"에 맞고, 매퍼는 규칙이라 원칙 1과 맞는다. 안개 사례(「구름 같은데 덜 빽빽하고 보이지 않는 안개같은?」, 「넓게 펼쳐진 안개」)는 이 경로로만 나아진다.
   - ①에서도 색·재질·크기·위치 말은 생성 프롬프트에 넣지 않는다. 그 값을 덮어쓰기로 넣을지는 ②–④와 같은 규칙을 쓸지 묻는다.
4. 위기 판정 순서·차단 사유를 참여자에게 알리지 않음·Ollama 내림 뒤 생성기 호출은 Claude 안대로.
5. 원칙 문구: 원칙 1 예외 문단은 Claude 안 3절 문장을 쓰되 "다시 적은 글로 스펙의 슬롯 값을 채우지 않는다"를 "다시 적은 글은 확정 스펙을 바꾸지 않고, 규칙이 읽은 값만 조절 단계의 처음 값으로 쓴다"로 바꾼다.
