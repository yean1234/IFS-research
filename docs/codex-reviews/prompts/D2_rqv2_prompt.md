## 검토해 달라는 것
각 항목에 대해 "문제 있음 / 문제 없음"을 먼저 적고, 문제가 있으면 구체적 반례나 실패 시나리오와 고칠 방법 하나를 적어라.
1. **Q1의 논리(3.1–3.2)**: "①에서만 가까운 > 먼"이 "머릿속 그림에 기댄다"를 뒷받침하고 "고른 값의 기억"을 배제하는가. ③인 속성에서도 값을 고르게 하는 것이 통제로 성립하는가, 다른 설명(요구 특성, 일관성 동기, 고르는 행위가 심상을 만들어 버림)이 남는가. 더 나은 통제가 있으면 하나 제시하라.
2. **가까운·먼 규칙**: w, p, δ 정의의 빈틈(색처럼 다차원인 속성, 기본값에서 온 w, p가 낱말 범위 밖, 범위 끝값, 무채색). 두 변형이 "원본에서 같은 만큼 다르다"가 지각적으로 성립하는가.
3. **Q2(3.3)**: 두 컨트롤러 간격과 자리 짚기가 심상의 크기·자리를 재는 타당한 보고인가. "보고와 관찰이 같은 화면이라 지각 압축이 상쇄된다"는 주장이 맞는가(운동 보고와 시각 관찰은 다른 양식이다). 데스크톱 비교 조건을 버린 것이 교수 지적 1에 충분한 답인가.
4. **Q3(3.4)**: 2×2 설계와 교차 대비가 이중 분리를 보일 수 있는가. '보기만' 조건의 고정 궤적이 적절한 통제인가. 네 칸에 같은 심상의 변형을 반복해 보여 줄 때 생기는 문제. 척도가 다른 두 지표를 견주는 방법.
5. **측정(3.5)**: '닮았다'와 '내 것처럼 느껴진다' 단일 문항을 형상마다 연달아 물을 때의 오염. 소유감 3문항을 한국어로 옮겨 쓰는 것의 문제. 빠진 필수 지표.
6. **통계**: Q1 확증 분석(속성을 묶은 혼합모형)의 단위와 무선효과 구조, 한 사람에게서 ①인 속성 수가 0–4개로 달라지는 문제, 20명에서의 검정력에 대한 솔직한 판단.
7. **원칙 위반**: AGENTS.md 원칙 1·2·3·7에 걸리는 곳. 특히 ③인 사람에게 값을 고르게 하는 것과 보기 전 질문 문구.
8. **단계 계획(6절)과 구현 목록(7절)**: 12/2까지 2주 안에 A 단계가 현실적인가. 빠진 구현 항목, 순서가 틀린 항목, 지금 코드 구조와 충돌하는 항목(파일:줄).
