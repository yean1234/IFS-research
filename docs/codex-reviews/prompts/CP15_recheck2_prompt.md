## 이미 알고 있는 것 (되풀이하지 말 것)
- 새 규칙은 일부러 넉넉하게 막는다. 정상 문장이 기각되는 것은 허용한다(예: '보면 쑥색이에요'가 가정으로, 같은 문장에 '사람'이 있으면 타인 말로, '지금' 없는 '쑥색으로 됐어요'가 과거로 기각). 과차단은 지적하지 마라.
- **매퍼 자체**가 부정·과거·타인 말·가정 문장에서 색을 채우는 문제는 따로 다룬다. 이번 범위가 아니다. 매퍼는 고치지 않았다.
- 검증기 규칙 판(`VALIDATOR_RULES`)을 기록과 캐시 키에 넣는 작업이 지금 진행 중이다.
- 실제 모델로 새 규칙을 다시 재지는 않았다. 실측에서 모델은 19문장 가운데 13문장에 빈 출력을 냈다.

## 확인할 것
1. CP15_recheck의 새 지적(닮은꼴·숫자 섞인 영어 값의 사유 일관성, 구분 표시를 모든 자료와 견주기, 번호를 못 찾을 때 예외, 건너뜀이 캐시를 덮어씀, 소유격·불규칙 복수 시험, 목록 해시와 캐시 키) 각각 "고쳐짐 / 일부 / 안 고쳐짐"과 근거(`파일:줄`).
2. **새 규칙을 빠져나가는 입력**(막아야 하는데 통과하는 것만): 과거·타인 말·가정 표지가 인용 문장의 앞 문장이나 뒤 문장에 있는 경우, 문장 나누기가 틀리는 경우(마침표 없음, 줄바꿈, 따옴표 안 문장), 높임·구어 어미 변형(~였거든요, ~다던데, ~래, ~라면서, ~였으면, ~일까 봐), 인용이 두 문장에 걸치는 경우. form 슬롯의 사람·동물 낱말이 합성어·준말·높임말(분, 아이, 애기)로 들어오는 경우. `has_attribute_word`가 속성 낱말이 아닌데 속성으로 받아들이는 경우(동음이의, 색 이름이 든 사물 '금색 반지'에서 색만 말했는지).
3. 플래그 건너뜀을 따로 적게 바꾼 것이 원칙 4를 약하게 하는 경로(건너뜀인데 캐시 값이 화면에 나가는 경우), 구분 표시를 못 찾아 건너뛸 때 확정 요청이 막히는 경로.
4. 플래그가 꺼진 설정의 출력·기록이 그대로인가. `llm.py`의 warmup 변경(num_ctx)이 면담·가드 모델 호출에 미치는 영향.
5. 새 시험이 위 규칙을 실제로 고정하는가.
