Claude 안을 뼈대로 채택했다.

| 항목 | 판정 | 이유 |
|---|---|---|

## 답할 것
1. **이 판정에서 틀렸거나 약한 곳**을 근거와 함께. 특히:
   - 다리 1회·은유 질문만으로 감정 형용사 → 구체 심상이 실제로 나올 것인가. 몸 감각 질문을 보류한 것이 연구 책임자의 목표(감정 형용사에서 출발해도 구체 심상이 나오게)를 못 채울 위험.
   - focus_hold 고정 문구가 정말 '감각의 질' 단계 역할을 하는가.
   - X 선택 규칙(focus_hold 답의 감각어 우선, 다음 opening의 감정어; 활용형뿐이면 X 없음)의 실패 사례를 한국어 예문으로.
   - 형상 신호 판정의 거짓 건너뜀·거짓 질문 사례를 한국어 예문으로(예: "마음이 무거워요", "머리가 하얘져요", "벽에 막힌 느낌", "구름 위에 있는 것 같아요").
   - 다리 답이 장면·기억·사람("시험 전날 같아요", "엄마 같아요")일 때의 처리.
   - 유도 오염과 RQ("내가 떠올린 모습과 닮았다") 해석 위험에서 빠진 것.
2. 각 지적마다 **구체적인 고침**(문구 원문, 규칙, 기록 항목)과 우선순위(반드시/권장/선택).
3. 당신의 원래 안에서 **끝까지 지켜야 한다고 보는 것**이 있으면 하나만, 왜 판정의 이유로는 부족한지.
4. 시험에서 꼭 넣어야 할 합성 첫 발화 15개(감정 형용사·추상 기분 서술·신체 은유·혼합)를 표로: 발화 | 기대하는 형상 신호 판정 | 기대하는 다리 질문 문장.
