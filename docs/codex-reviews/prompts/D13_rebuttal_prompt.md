# D13 판정 반박

당신은 이 저장소의 외부 검토자입니다. 파일을 고치지 말고 한국어로 답하세요. 과제는 `docs/codex-reviews/prompts/D13_prompt.md`, 두 독립안은 `docs/codex-reviews/D13.md`(Codex)와 `docs/codex-reviews/D13_claude.md`(Claude)입니다. 원칙 `AGENTS.md`, 뼈대 `docs/design-backbone.md`.

## 메인의 잠정 판정 (반박할 대상)
1. 두 안이 모두 (a)로 일치했다. **세션 안 경로는 원칙 1을 그대로 둔다**(12-02 포함). 연구 책임자가 원한 "LLM이 근거 태그를 달아 JSON을 만든다"는 세션 안에서는 채택하지 않는다. 이유: 과한 해석을 막는 유일한 기계 검사는 "인용 낱말이 그 슬롯의 차원을 직접 가리키는가"인데 그 목록 자체가 사전이다(Claude 안). 참여자 확인은 암시를 없애지 못한다(두 안).
2. Claude 안의 **a′를 채택**한다: 세션 밖에서 로컬 LLM이 `_unmatched` 낱말에 대해 사전 항목 후보(슬롯·값·근거 유형)를 제안하고, 사람이 검토해 새 사전 판에 넣은 것만 매퍼가 쓴다. 사전 항목에 `src: llm_proposal:<run id>`, 검토자·날짜를 적는다. 원칙 1에 "세션 밖 사전 후보 제안" 하위 항목을 더한다. 12-02 전에는 새 사전 판을 넣지 않는다.
3. (b)(세션 안 빈칸 채우기)는 닫지 않고 **오프라인 평가의 결과로만 다시 연다**. 평가 도구를 만들어 합성 대사에서 기계로 잴 수 있는 것(인용 불일치, 매퍼 충돌, 빈칸 채움률, 같은 PC 반복 일치율)을 먼저 재고, 사람 판정(과한 해석률, 두 명·κ)은 연구 책임자 일정에 맞춰 뒤에 한다. 통과 기준은 두 안 가운데 엄한 쪽: 근거 없는 값 0, 과한 해석 ≤1%(95% 상한 ≤2%), 매퍼 충돌 0, 반복 일치 100%, κ ≥ 0.70, 교차 감각·감정어 통과 0건. held-out은 사전을 보지 않은 사람이 쓴 대사로 한다.
4. 12-02의 그림자 모드(LLM 추출을 기록만)는 하지 않는다: 동의서가 다루는 범위가 불분명하고 Codex 안이 참여자 발화 캐시를 합성 자료에 한정하라고 했다.

## 할 일
위 판정의 약점을 찾아 반박한다. 특히: (가) a′가 연구 책임자의 문제("사전의 한계가 너무 뚜렷하다")를 실제로 줄이는가, 아니면 문제를 미루기만 하는가. 실험 중 처음 나온 낱말은 여전히 못 읽는다. 대안(예: 조절 화면에서 참여자가 직접 채우는 것으로 충분한가, [맞는 게 없어요] 뒤 이미지 후보 고르기 G75가 이 빈자리를 얼마나 메우는가)을 따진다. (나) a′의 사람 검토가 사실상 도장 찍기가 되어 LLM 추론이 사전으로 세탁될 위험과 막을 절차. (다) 통과 기준 숫자가 표본 수로 달성 가능한가(1%·상한 2%에 필요한 표본). (라) 그림자 모드를 뺀 판단이 과한가. (마) 원칙 문장을 어떻게 바꿔야 하는가.
