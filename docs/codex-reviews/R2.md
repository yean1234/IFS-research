웹 검색으로 공식 문서·출판사 페이지·논문 원문을 확인했습니다. 파일은 수정하지 않았습니다. 아래에서 “일부”는 서지나 큰 방향은 맞지만, 설명의 범위·비교 대상·해석을 좁혀야 한다는 뜻입니다.

## 결론에 영향을 주는 오류

1. **MentalImager 결과 해석이 뒤집혔습니다.** 원문은 순수 키워드 프롬프트의 우위를 보인 것이 아니라, 감정어와 제목 주제어를 함께 넣은 조건이 더 높은 관련성 평정을 보였다고 보고합니다. 이를 “규칙 키워드가 전문 프롬프트보다 낫다”는 근거로 쓰면 안 됩니다.

2. **Refugio를 ‘LLM 비사용/재작성 없음’ 대조 사례로 분류한 것은 근거가 약합니다.** 실제로 LLM이 사용자 요청을 검증·구조화하는 데 들어갑니다. 시스템의 사용 목적과 이미지 프롬프트를 작성하는 경로를 분리해 확인해야 합니다.

3. **2.05배는 조건부 결과입니다.** 특정한 AI 편집 이미지 기반 영상 조건의 거짓 기억 수이며, 생성 이미지 전반이나 자기성찰 장면 생성의 효과를 직접 입증하지 않습니다. 이 연구를 현재 연구의 직접 위험 추정치처럼 제시하면 안 됩니다.

4. **반대 방향 문헌이 빠져 있습니다.** Jahani 외의 2024 온라인 실험(N=1,891)은 DALL·E 3의 자동 프롬프트 수정이 이미지 재현 과제에서 DALL·E 3의 성과 이점을 58% 줄였다고 보고합니다. 이는 재작성의 위험만이 아니라 과제에 따라 **자동 재작성 자체가 사용자 성과를 낮출 수 있음**을 보여주는 직접 비교 자료입니다. [Microsoft Research 요약](https://www.microsoft.com/en-us/research/publication/as-generative-models-improve-people-adapt-their-prompts/). 반면 과제는 목표 이미지 재현이지, 내적 경험의 표현 충실도는 아닙니다.

따라서 문서의 큰 결론인 “자유 문장 재작성을 제한하고 규칙 기반 경로를 우선 검토한다”는 **설계 판단**으로는 유지할 수 있지만, 현재 제시된 문헌만으로 “참여자 심상에 더 충실하다”거나 “규칙 키워드가 LLM보다 낫다”고 실증 결론처럼 쓰기는 어렵습니다.
