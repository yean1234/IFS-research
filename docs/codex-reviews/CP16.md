## 문제없다고 확인한 것

- 새 네 문구 키는 두 문구 파일에 각각 0.8과 0.8-scaleA로 추가됐고, 키별로 `draft` 상태와 2026-11-28 출처가 있습니다. 기존 문구 파일은 새 키가 없어도 읽히도록 선택 키로 처리됩니다.
- 연습 라운드 상한은 라운드 계획의 연습 여부로 골라 적용됩니다. 연습 0회면 연습 상한 검증을 생략하고, 단일 멈춤 모드에서는 이 값이 적용되지 않습니다.
- 확정 안내와 본 측정 시작 문구는 표시만 바꾸며, 라운드 종료 기록이나 다음 라운드 시작 시각을 직접 바꾸지 않습니다. 알림은 단계 전환 때 초기화됩니다.
- 일반 보기 모드에서는 확인 버튼 안내가 붙지 않습니다. 위 지적은 `view + point_select` 조합에 한정됩니다.
