# D8 설계안 (Claude 하위 에이전트, 독립안)

프롬프트: `docs/codex-reviews/prompts/D8_prompt.md`. 읽은 파일: `AGENTS.md`, `shared/schemas/selection.v0.2.json`, `shared/schemas/scene-spec.v2.3.json`(form·layout 절), `docs/gen3d-feasibility.md`(요약·수치 절), `research_notes/심상 외부화 3D 생성 모델 검토/local_3d_generation_models.md`(grep), `tools/gen3d/prompts.py`(grep), `docs/decisions.md` G5·G7·X40·G45–G51.

전제 하나를 먼저 반대한다. "형태는 생성 모델로 만든다"를 **생성 메시가 기본 형태**라는 뜻으로 읽으면 안 된다. 11-22 측정에서 규칙 프롬프트 경로는 60개 중 '맞음' 0개였다. 생성 메시는 **후보를 내는 출처 하나**로 넣고, 절차 메시는 기준 후보이자 실패 시 대체로 남긴다.

## 1. 원칙 1·2 새 문구

**1.** LLM은 면담 질문을 만드는 데만 쓰고, 장면 속성 값(SceneSpec 슬롯)은 사전·규칙만 정한다. 형태 메시는 digest·seed를 고정한 로컬 형태 생성 모델이 만들 수 있으나, 입력은 규칙이 SceneSpec의 말한 값에서 만든 프롬프트뿐이고 그 출력을 슬롯 값으로 되돌려 쓰지 않는다. LLM이 프롬프트를 쓰거나 고치는 것, 생성 결과로 색·재질·크기·거리를 정하는 것은 금지다.

**2.** 사용자가 답하지 않은 내용을 시스템이 값으로 추론하지 않으며, 말한 것이 추론한 것을 덮어쓴다. 생성 메시가 채운 형상 세부는 '생성'으로 표시해 말한 것·고른 것과 섞지 않고, 참여자가 고르기 전에는 확정 형태로 쓰지 않는다. 형태 서술이 없는 발화에서는 생성하지 않는다(빈 슬롯은 빈 슬롯으로 둔다).

## 2. 파이프라인에서의 자리

- **실행 중 생성(데스크톱 4단계, VR 전)과 내용 주소 캐시를 함께 쓴다.** 키는 sha256(프롬프트 + 모델 digest + seed + 정규화 판)이다. 같은 키면 같은 GLB를 쓰므로, 합성 코퍼스를 미리 돌려 두면 사실상 미리 만든 묶음이 된다. VR 안에서는 생성하지 않는다. 지연 문제도 있고, 안전 관문을 거치지 않은 메시가 나타날 수 있기 때문이다.
- 후보 집합은 절차 메시 기준 후보 1개와 생성 후보 최대 2개(seed 0·1)다. 생성 후보는 관문(5절)을 통과한 것만 넣는다. G34의 "구별되는 후보 하나뿐이면 건너뜀"은 생성 후보에 적용하지 않는다. 생성 후보는 반드시 고르게 해야 하고, 자동으로 확정되지 않는다.
- **생성하지 않는 경우**: 형태 내용어가 없음, 사전에 없는 명사만 있음, 제외 범주(G46·G50·G51)에 걸림, 관문을 모두 탈락함. 이때는 지금처럼 `form.type`/`form.base` 절차 메시나 기본값을 보이고, 이유를 기록한다.
- **메시로 만들지 않는 범주**: `form.type = mist`, `form.base = flame`, 안개·연기·불꽃·빛 낱말은 생성을 금지하고 절차·입자 경로로 보낸다. 얇은 것(`line`·`sheet`·천·종이)은 SDF 계열에서 알려진 실패 유형이므로 절차 메시를 기준 후보로 두고, 생성 후보는 `thinFormRisk` 표시를 붙여야만 낸다.

## 3. 모델

- **첫째: TripoSG(MIT, 형태만, 8 GB 이상).** 앞단은 이미 캐시에 있고 결정성을 확인한 SDXL base 1.0을 그대로 쓴다. 근거: 의존성이 순수 PyTorch에 가깝고, 기존 py3.11·cu128 환경을 재사용할 가능성이 가장 높으며, 출력에 질감이 없어 요청 2(색·질감은 매핑)와 맞는다. 배경 제거용 `briaai/RMBG-1.4`는 라이선스 조건을 확인해야 한다. 걸리면 이미 쓰고 있는 rembg(u2net)로 바꾼다.
- **중단 기준**: 11-29 정오까지 TripoSG가 이 PC에서 GLB를 내지 못하면 이미 돌아가는 TripoSR로 같은 인터페이스를 채운다. 논문에는 그렇게 적는다.
- **둘째: Roblox Cube 3D v0.5.** 텍스트에서 바로 형태를 만들어 이미지 단계의 지어냄 한 층이 빠지고, 경계 상자 조건으로 `form.aspect`를 직접 넣을 수 있다. 그래서 설계상으로는 TripoSG보다 낫다. 다만 라이선스 본문을 읽지 않았고 16 GB가 경계선이라 12-02 전에는 넣지 않는다.
- TRELLIS.2·Pixal3D는 휠이 cp310뿐이고 의존 모델이 게이트되어 있어 12-02 전에는 불가능하다.

## 4. 스키마·기록

- **scene-spec 2.3은 바꾸지 않는다.** 생성 결과는 슬롯 값이 아니므로 spec에 넣지 않는다(원칙 1).
- **새 부속 파일 `shared/schemas/form-asset.v0.json`**(세션 폴더, git 밖)을 둔다. 후보마다 다음을 적는다.
  - `assetSha256`(GLB), `cacheKey`, `model{repo, hfRevision, weightFileSha256[], codeCommit}`, `frontEnd{같은 항목}`, `torch·cuda·driver`, `seed`
  - `prompt{text, template판, rulesVersion, contentTokens[{en, ko, charSpan, slot}], negativeTemplate}`, `intermediateImageSha256`
  - `normalization{rawBbox, scale, pivot, 판}`, `gate{siglip점수, 사람·얼굴·동물·무기 점수, 판정, 사유}`, `thinFormRisk`
- **selection.json은 `ifs-selection/0.3`으로 올린다.** 출처 enum에 값을 더하면 0.2만 아는 러너가 파일을 거부하므로, 하위 호환 추가로 처리할 수 없다.
  - 출처 값 추가: `generated_chosen`. 생성 후보를 고른 뒤 형태를 바꾸면 기존 규칙대로 `edited`.
  - 후보 sources 값 추가: `generated`.
  - `flatOverrides` 키 추가: `form.asset`(assetSha256).
  - `sourceDetails.form.type.generation`: 생성 안 함 사유, 또는 assetSha256.
  - `generationLog[]`: 관문 탈락, '맞는 것이 없다' 거부, 시각.
  - 러너는 0.1·0.2·0.3을 모두 읽는다. 0.2 파일은 그대로 유효하다.

## 5. 거리 결과변수를 지키는 장치

- **크기**: 축 정렬 경계 상자의 가장 긴 변을 절차 메시 기본 형상과 같게 맞춘다(오차 ±1%). 그 뒤 `layout.size` 조절은 지금과 같은 로그 척도를 쓴다. 정규화 전 치수와 축 비율은 기록한다.
- **방향**: 모델의 y-up만 쓰고 임의로 회전하지 않는다.
- **바닥·그림자**: 피벗은 경계 상자 중심이다. 높이·그림자·조명은 절차 메시와 같은 설정을 쓴다. 정규화 뒤 최저점 높이를 기록한다.
- **사람·얼굴·동물**: 이중으로 막는다.
  - 프롬프트 단계: 기존 제외 판정을 그대로 쓴다. 사람·동물 명사에서는 생성하지 않는다.
  - 출력 단계: 6시점 렌더를 SigLIP 영점 분류(person / face / eyes / animal / weapon)에 넣고, 고정 문턱을 넘으면 탈락시킨다.
  - 이 고정 부정 템플릿("no face, no eyes, no figure")은 묘사가 아니라 안전 제약이다. 모든 프롬프트에 똑같이 붙이고 기록한다.
- **공변량**: 생성/절차 여부, seed, 축 비율, 볼록 껍질 대비 부피, 표면적/부피, 삼각형 수, 좌우 대칭도, 사람·동물 유사 점수, 문장-형태 SigLIP 점수, '익숙한 사물 명사를 말했는가'(Rzepka 2023: 익숙한 크기 단서는 정규화로 없앨 수 없다).

## 6. 프롬프트 만들기 (LLM 없음)

- `tools/gen3d/prompts.py`의 rules 모드를 확장한다. 새 사전 `shared/lexicon/form_prompt_en.v0.json`(한국어 형상 명사·모양어·자세어 → 영어 고정 대응)을 둔다.
- **넣는 것**: SceneSpec에서 `_provenance`가 said인 형태 슬롯(`form.*`)과 중심 명사만 넣는다. 색·재질·밝기는 넣지 않는다. 형태만 생성하고 색은 매핑이 정한다.
- **넣지 않는 것**: `_negated`, `_inferred`, 빗댐 원천(G45), 사전에 없는 낱말. 사전에 없는 낱말은 음역하지 않고 생성을 건너뛴다.
- **템플릿**: "a single {content}, matte gray clay, plain background" 형태로 고정하고, 판을 기록한다.
- **감사**: 프롬프트의 모든 내용 토큰은 charSpan이 있는 한국어 낱말로 거슬러 가야 한다. 하나라도 못 가면 생성을 막는다(fail closed). 템플릿 낱말은 별도 목록으로 두고 분석에서 뺀다.

## 8. 가장 약한 점 3개와 논문 서술

1. **원칙 2가 "막음"에서 "표시함"으로 약해진다.** 생성기는 말하지 않은 기하 세부를 반드시 채우고, seed는 연구자가 고른 값이다. 논문에는 "생성 모델은 서술되지 않은 형상 세부를 채우며, 우리는 내용 토큰을 발화 근거로 제한하고 그 결과를 '생성' 출처로 구분했다"고 쓰고, 지어냄 비율을 수치로 보고한다.
2. **거리 결과의 교란.** 생성 형태는 참여자가 고른 것이라 무작위 배정이 아니다. 정규화는 크기만 맞추고 익숙함과 형상다움은 맞추지 못한다. 논문에서는 생성 형태 여부를 공변량·층으로 두고 인과 주장을 하지 않는다고 적는다.
3. **타당도 근거의 부재.** 참여자 없이 합성 문장, 연구팀 판정, SigLIP 점수만 있다. "내 심상과 맞다", 소유감, 거짓 기억·불안 위험(Pataranutaporn 2025; Worry Gallery 2026)은 검증하지 않았다. 논문에서는 이 경로를 "통합과 합성 측정 결과"로 한정하고, 참여자 효과는 IRB 이후 과제로 명시한다.
