## 1. 진단

- **첫 질문:** G60은 “어떤 느낌”을 묻고 감정 형용사나 추상 기분만으로도 답할 수 있어, 형상을 말하게 하는 다리가 없다.
- **find:** 몸 위치 고정 문구 뒤에도 LLM은 `anything_else` 또는 `like_what`을 한 번만 고른다. 형상이 없는 감정어를 받아도 흐름을 바꾸지 않으며, 틀 선택 규칙도 없다.
- **flesh_out:** 최대 5회라도 감정어를 인용해 되묻는 질문이 가능하다. 형상 표현을 새로 끌어내도록 짜여 있지 않고, 짧은 답이면 질문을 건너뛴다.
- **프로브:** 마지막의 크기·모양·색·밝기·움직임 질문은 한 번씩만 하고 무응답도 허용하므로, 형상이 끝까지 비어도 확정에 도달한다.
- **인용 후보:** 감정어는 낮은 순위 후보이고 미등록 감정어는 후보에서 빠질 수 있다. 용언 어간을 그대로 인용하면 “그 ‘설레요’는 어떤 ‘설레요’인가요?” 같은 질문도 생긴다.

## 2. 설계안 하나: 공통 최소 경로 + 형상 미확정 분기

**모든 참여자에게 같은 질문 순서를 적용한다.** 발화 종류에 따라 프로토콜을 갈라 감정 응답자만 다른 경로로 보내면 조건별 면담량과 질문 노출이 달라진다. 대신 규칙 기반 판정은 **아직 참여자가 형상을 말했는지**를 가리는 데만 쓴다. 자유 텍스트를 모델로 분류하지 않고, 결정론적 사전·문법 규칙을 사용한다.

1. G60 오프닝은 유지한다. 이어 현행 위치 질문 **“그것이 몸 안에, 몸 표면에, 아니면 몸 주변에 있나요?”**를 묻는다.  
2. 형상 표현이 없으면 고정 다리 질문 **“‘{참여자 표현}’은 지금 몸에서 어떻게 느껴지나요?”**를 한 번 묻는다. 참여자가 이미 말한 표현의 원문 부분 문자열만 넣는다. 출처는 Focusing의 *felt sense* 탐색을 참고한 **연구진 번안**, status **draft**다. 위치를 이미 답했어도 감각의 질을 참여자 말로 받으려는 단계다.  
3. 새 답에 형상 표현이 여전히 없고, 참여자가 짧은 거절·모름을 보이지 않았을 때 고정 질문 **“그리고 ‘{참여자 표현}’은 마치 무엇 같나요?”**를 한 번 묻는다. Clean Language의 “And that’s X like what?”을 참고한 번안, **draft**다. `like_what`은 이 조건에서만 강제한다. 형상 유무는 사전 등록된 사물·형태·색·크기·질감·공간 표현 또는 참여자가 만든 직유의 명시적 표지 등으로 판정한다. **감정·감각 단어만 있거나 사전에 없는 내용어가 있다는 이유만으로 형상이 있다고 추정하지 않는다.** 인식되지 않은 표현은 `unclassified`로 두고, 이를 형상 슬롯에 자동 반영하지 않는다.  
4. 형상이 생기면 현행 flesh_out으로 넘어간다. 형상 슬롯이 비어 있으면 현행 차원 프로브가 직접 묘사어를 제안해 유도할 위험이 있으므로, 개정안에서는 이를 **중립적인 형상 확인 뒤**에 두고 기존 프로브 문구도 유도 오염 검토 대상으로 표시한다. IFS의 Flesh out은 참여자 표현을 더 펼친다는 근거이지, 시각 차원을 면담자가 먼저 제시해야 한다는 근거는 아니다.

Focusing의 다리는 “몸에서 어떻게 느껴지나요?”로 감각을 묻고, Clean 질문은 참여자가 이미 쓴 X를 그대로 되묻는다는 점에서 순서가 맞다. 색·형태·질감은 미리 나열하지 않는다. 추가 다리는 **최대 두 번**이다. “없어요”, “모르겠어요”, “안 보여요”라고 하면 그 지점에서 종료하거나 기존 절차로 넘어가고, 같은 질문을 되풀이하지 않는다. 거절 여부를 되묻지 않고 **미응답·미지정**으로 기록한다. 끝까지 형상이 없으면 슬롯은 빈 채로 확정하고, 기본값이 쓰이는 경우에도 참여자 진술과 분리해 출처를 기록한다. 이는 G19 및 G60-2b의 “참여자가 정하지 않은 값은 비운다”는 원칙과 일치한다.

**표현 처리:** 조사는 원문 문자열을 기계적으로 붙이지 말고, 인용한 구절의 한국어 문법에 맞는 조사만 결정론적으로 붙인다. ‘불안’ 뒤에 ‘은/는’을 선택할 때도 원문 어절 경계를 보존한다. 어간만 잘라 인용하지 않는다. ‘설레요’는 용언 활용형 자체가 참여자 표현이므로 그 전체를 인용할 수 있지만, 이를 다시 같은 단어로 정의하라는 `what_kind` 질문은 선택하지 않는다. 사전에 없는 ‘기대’도 원문 인용은 가능하게 하되, 감정 범주나 형상 슬롯에 넣지 않는다. 표현 분석 실패는 질문 실패가 아니라 인용 후보 없음 또는 미분류 상태로 남긴다.

## 3. 원칙 및 유도 오염 점검

| 질문 | 원칙 2·3·8 점검 |
|---|---|
| 현행 위치 질문 | 세 선택지를 면담자가 제시한다. 이미 고정된 승인 문구로서 유지 여부는 연구팀·IRB 검토 대상이다. 새 다리에서 선택지를 더 늘리지 않는다. |
| “{표현}은 지금 몸에서 어떻게 느껴지나요?” | ‘몸’은 참여자 말이 아닐 수 있고, 답을 신체 감각으로 좁힌다. 고정 질문이어도 유도 위험이 있으므로 **draft**로만 다루고, 응답은 실제 발화대로 기록한다. |
| “{표현}은 마치 무엇 같나요?” | 비유 형태를 면담자가 요청하므로 원칙 3의 “면담자가 비유를 먼저 내지 않는다”와 긴장이 있다. Clean Language의 X→like what 틀을 쓰되, X와 질문 대상은 참여자 표현에 한정하고 감정의 물체화를 전제하지 않는다. |

다리 질문은 ‘모양’·‘보이다’ 같은 시각 양식을 직접 요구하지 않더라도 **감각과 은유를 먼저 부르는 조작**이다. 외부화한 형상이 “내가 떠올린 모습과 닮았다”는 RQ에 영향을 줄 수 있으므로 질문 노출 여부와 순서를 기록하고, 사후 유사도 응답을 질문 경로별로 검토한다. 질문 경로가 RQ 자체를 바꿀 수 있다는 점을 한계로 명시한다. 질문 문구·분기 규칙은 모두 조건 간 동일하게 관리한다. V1–V9를 약화하는 변경은 제안하지 않는다. 고정 질문은 V1–V9를 통과하지 않으므로, 참여자 표현 삽입과 길이·유도어 여부를 별도로 결정론적으로 검사한다.

## 4. 조건 1과의 형평

정적 조건에도 **동일한 고정 다리 문구와 동일한 형상 미확정 분기**를 넣어야 한다. 그래야 LLM 유무가 주된 조건 차이로 남고, 새 유도 질문의 유무가 집단 차이와 섞이지 않는다. 조건 1에서 사용할 위치·거절 응답 분기와 횟수도 조건 2와 같게 한다. 다만 공통 질문을 추가하면 연구 조작과 절차가 바뀌므로 프로토콜 새 버전 및 문구 상태 변경을 함께 기록한다.

## 5. 시험 계획

합성 대화 재생 시나리오에 “불안해요”, “기대돼요”, “숨막혀요”, “답답해요”, “모르겠어요”, “안 보여요” 같은 시작 응답을 넣고, 각 대화에서 위치 응답·다리 응답·직유 응답을 고정해 재생한다. 구현 검증에는 가상 참여자 LLM을 쓰지 않는다. 정해 둔 응답 목록이면 같은 입력에서 같은 분기·질문을 재현할 수 있고, 생성형 응답은 재현성과 질문 품질 평가를 혼합한다. 지표는 형상 슬롯별 참여자 명시 발화 비율, 다리 도달·응답·거절 비율, 사전에 없는 표현의 미분류율, V1–V9 위반 수, 어색한 조사·용언 반복 질문 수, 조건별 질문 횟수다. “슬롯 채움”은 추출 성공과 참여자 발화 발생을 따로 센다. 선행 연구 응답을 쓰려면 사용·재사용 권한과 맥락·번역 적합성을 확인하고, 실제 참여자 원자료라면 접근 통제와 저장·반출 규칙을 적용한다. 시나리오에는 합성 대사만 둔다.

## 6. 구현 순서

1. `docs/decisions.md`에 다리, 공통 순서, 분기 기준, 미응답 처리, 유도 위험을 결정 기록으로 추가한다.  
2. `shared/protocol/elicitation_protocol.v1.4.json`을 새 버전으로 올리고 두 조건에 같은 새 고정 문구와 단계·횟수·status·출처를 기록한다. 이전 버전은 보존한다.  
3. 새 프롬프트 버전에서 다리 분기 이후의 LLM 허용 틀과 인용 지침을 조정한다. 새 질문도 참여자 발화에 실제로 포함된 원문만 인용하도록 한다.  
4. `controller.py`에 규칙 기반 형상 미확정 분기와 최대 질문 수를 넣고, `anchors.py`의 감정어·용언 후보 조사 처리를 다듬는다. `extract.py`는 미등록어를 추론 슬롯에 넣지 않고 미지정 상태로 보존한다.  
5. 검증기는 새 고정 질문에 대해 인용 출처·분기 조건·금지 유도어를 검사하되, V1–V9는 약화하지 않는다. 사전은 연구자 승인 항목만 추가하고 새 어휘가 곧 형상 판정이 되지 않게 한다.  
6. 시나리오·테스트는 합성 대화 재생으로 작성한다. 새 분기는 설정 기본값에서 꺼서 예전 기록의 추출·대화 결과가 그대로 재현되게 하고, 새 프로토콜을 명시한 실험에서만 켠다. 위험은 다리 자체가 답을 시각·은유 쪽으로 몰 수 있다는 점, 규칙 분류의 누락·오분류, 고정 문구와 LLM 후속 질문 간 노출량 차이다.
