| 지적 | 상태 | 근거 |
|---|---|---|
| 닮은꼴 문자·숫자 섞인 영어 값의 사유 일관성 | **고쳐짐** | 허용 형식 밖 문자는 금지어 검사 전에 `english_format` 하나로 기각합니다. 대표 입력 시험도 있습니다. `tools/gen3d/prompts.py:492-507`, `chatbot/tests/test_g77_llm_fill.py:414-419, 442-443` |
| 구분 표시를 모든 자료와 대조 | **고쳐짐** | 원문, 어절, 채운·제외·미분류 자료, 슬롯 안내, 템플릿, system 문구를 후보 번호 검사에 넣습니다. `chatbot/ifs_chatbot/llm_fill.py:224-234, 237-259` |
| 표시 번호를 못 찾을 때 예외 없이 처리 | **고쳐짐** | `None`을 반환하고 `fence_unavailable`로 건너뛰므로 확정 흐름을 멈추지 않습니다. `chatbot/ifs_chatbot/llm_fill.py:224-234, 599-601`; 시험은 `chatbot/tests/test_g77_llm_fill.py:607-635` |
| 플래그 건너뜀이 성공 캐시를 덮어씀 | **고쳐짐** | 플래그 분기는 캐시에 쓰지 않고 `llm_fill_skips`에 따로 기록합니다. `chatbot/ifs_chatbot/llm_fill.py:559-586`; 시험은 `chatbot/tests/test_g77_llm_fill.py:473-489` |
| 소유격·불규칙 복수 시험 | **고쳐짐** | 소유격은 형식 위반으로, 불규칙 복수는 금지 사유로 시험합니다. 서버 검증과 생성기 재검증이 같은 함수를 씁니다. `tools/gen3d/prompts.py:492-507`; 시험은 `chatbot/tests/test_g77_llm_fill.py:402-429, 454-462` |
| 영어 금지 목록 해시와 캐시 키 | **고쳐짐** | 목록 파일 해시가 기록과 캐시 키에 들어가며, 해시 변경 시 새 키를 쓰는 시험이 있습니다. `chatbot/ifs_chatbot/llm_fill.py:123-124, 557`; 시험은 `chatbot/tests/test_g77_llm_fill.py:515-526` |

추가 확인: 플래그가 있으면 캐시 조회를 건너뛰고, 선택 단계도 처음 값과 생성 형태를 다시 걸러냅니다(`chatbot/ifs_chatbot/llm_fill.py:559-586`, `chatbot/ifs_chatbot/selection.py:275-282, 298-317`). 플래그가 꺼진 설정은 런타임에서 빈칸 채우기 프롬프트를 만들지 않고 선택 경로도 기존 판을 유지합니다(`chatbot/ifs_chatbot/controller.py:219-224`, `chatbot/ifs_chatbot/selection.py:269-273, 295-296`). 워밍업은 실제 면담·구조화 호출과 같은 `num_ctx`를 사용하므로 호출 설정에 새 차이는 없습니다(`chatbot/ifs_chatbot/llm.py:103-112, 137-170`). **새 규칙을 고정하는 시험은 일부 사례에 한정**되어 아래 미시험 경로가 남습니다.

## 새로 찾은 문제

- **높음** — `chatbot/ifs_chatbot/llm_fill.py:304-306, 318-326`; `chatbot/ifs_chatbot/scene_builder_v1.py:128-136`  
  재현 입력: `친구가 그게 쑥색이라고 했어요. 내 덩어리는 쑥색이에요.` 인용을 두 번째 문장의 `쑥색`으로 주면, 프레임 검사는 인용 문장만 훑어 앞 문장의 전언 표지를 놓칩니다. 뒤 문장에만 있는 표지도 같은 방식으로 놓칩니다. 덧붙여 입력 정규화가 줄바꿈을 공백으로 합치므로, 줄바꿈 자체는 문장 경계로 보존되지 않습니다(`chatbot/ifs_chatbot/korean.py:27-32`).  
  고칠 방향: 인용 문장만 검사할지 인접 문장까지 검사할지 규칙 범위를 정하고, 줄바꿈·인용부호 경계를 포함한 시험을 추가하세요.

- **중간** — `chatbot/ifs_chatbot/llm_fill.py:340-350`; `chatbot/tests/test_g77_llm_fill.py:638-656`  
  재현 후보: `쑥색이라면서요`, `쑥색이라던데요`, `쑥색일까 봐요`. 현재 전언·가정 판정은 제한된 어미 목록과 정확한 형태 비교에 의존합니다. 이 변형들은 새 시험에 없고, 목록에 직접 대응하는 형태도 보이지 않습니다. **추측:** 형태소 분석 결과가 목록과 다른 EC·ETM 형태로 나오면 통과할 수 있습니다. `~였거든요`, `~였으면`, `~래`처럼 기존 규칙에 잡힐 수 있는 변형과 실제 통과 여부도 시험으로 확인되지 않았습니다.  
  고칠 방향: 요청된 어미 변형을 Kiwi 분석 결과별로 합성 시험에 넣고, 기각 사유를 고정하세요.

- **중간** — `chatbot/ifs_chatbot/llm_fill.py:287-301, 443-449`; `chatbot/tests/test_g77_llm_fill.py:677-686`  
  재현 후보: `그분 모양이에요`, `애기 모양이에요`에서 `form` 값을 제안하도록 합니다. 형태 슬롯 차단은 차단 목록의 명사 표면형과 정확히 일치하는지 확인합니다. 따라서 목록에 없는 높임말·준말·합성어 형태가 한 명사 토큰으로 분석되면 빠질 수 있습니다. 새 시험은 `사람`, `고양이`, `안개`, `불꽃` 등의 기본형만 다룹니다.  
  고칠 방향: 실제 형태소 분석 결과를 확인해 `분`·`애기`·합성어 사례를 시험에 추가하고 필요한 표기를 차단 목록에 명시하세요.

- **중간** — `chatbot/ifs_chatbot/llm_fill.py:362-387`; `chatbot/tests/test_g77_llm_fill.py:689-711`  
  재현 입력: 밝기 슬롯에 `길어요`를 인용하고 `bright`를 제안하거나, 색 슬롯에 `색깔`만 인용하고 `green`을 제안합니다. 밝기·투명도·질감은 여러 슬롯에서 같은 “형용사 품사” 조건을 통과하고, 색은 특정 색 이름이 없어도 `색깔` 꼬리로 통과할 수 있습니다. 두 문장에 걸친 짧은 인용도 배제하지 않으므로 `"길어요. 덩어리"` 같은 인용이 밝기 근거로 받아들여질 여지가 있습니다. 새 시험은 무관한 명사·동사를 기각하지만 이 품사·일반 명사 경로는 고정하지 않습니다.  
  고칠 방향: 슬롯별 속성 어근과 명시적 측정 표현으로 통과 조건을 좁히고, 동음이의·일반 명사·문장 간 인용 사례를 추가하세요.

정적 코드 검토이며 시험은 실행하지 않았습니다.
